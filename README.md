# Product Sales Analysis

A data analysis project focused on understanding customer purchasing behavior and sales trends using transactional sales data.

## What it does

* Cleans and preprocesses sales transaction data
* Extracts time-based features such as hour and day periods
* Analyzes customer purchase patterns and busiest sales hours
* Visualizes category and purpose distributions using charts and plots
* Applies feature engineering and encoding techniques for analysis

## Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

## Conclusion

* Sales analysis helped identify peak purchasing hours and customer behavior trends
* Data visualization provided insights into product categories and sales distribution
* Feature engineering improved understanding of transactional patterns
